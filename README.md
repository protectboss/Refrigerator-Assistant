# 冰箱助手

记录买回来的菜、自动设置保质期、临期提醒、按库存推荐今日菜谱并生成缺料购物清单,帮你告别"菜放到坏才想起来"。

本仓库包含两个版本,功能一致:

| 版本 | 目录 | 状态 |
| --- | --- | --- |
| **网页版 PWA(主力)** | `webapp/` | 无需任何账号,部署后手机浏览器"添加到主屏幕"即可像 App 一样使用 |
| 微信小程序 | 其余文件 | 保留;以后拿到小程序 AppID 可继续使用 |

## 功能

- **冰箱库存**:按剩余天数排序,最急的排最上面;临期(≤2 天)标橙、过期标红,顶部横幅提醒
- **录入菜品**:输入名称自动联想,命中内置知识库(约 50 种常见食材)后自动填写保存位置、参考保质期和保存建议(如"土豆:阴凉避光,不要进冰箱"),到期日期和建议都可手动修改
- **消耗记录**:点击菜品可标记"吃完了 / 扔掉了"(历史留存,为后续浪费统计做准备)或编辑
- **今日吃什么**:根据冰箱现有食材匹配内置家常菜谱,优先推荐能消耗临期食材的菜;缺的食材一键加入购物清单
- **问问 AI(网页版)**:和通义千问对话,基于冰箱实时库存推荐做菜方案,优先消耗临期食材,缺的食材会提示购买
- **拍照识别(网页版)**:拍食材照片或超市购物小票,AI 自动识别出食材清单,勾选确认后按知识库自动设置保质期批量入库
- **到期通知(网页版)**:授权后每天打开应用时自动弹系统通知提醒临期菜品
- **离线可用(网页版)**:Service Worker 缓存后,没网也能打开

## AI 功能配置(必需自己的 API Key)

1. 到[阿里云百炼控制台](https://bailian.console.aliyun.com)创建 API-KEY(格式 `sk-...`)
2. 打开应用 → 右上角**设置** → 粘贴 Key → 保存

Key 只保存在设备本地的浏览器存储中,不进代码仓库、不上传第三方;AI 请求经由自己部署的
Cloudflare Worker(`worker.js`)转发到阿里云 DashScope 兼容接口。
对话使用 `qwen-plus`,拍照/小票识别使用 `qwen-vl-max`,按量计费。查看库存

## 网页版:本地预览

```bash
cd webapp
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 网页版:部署上线(免费,推荐 Cloudflare Pages 或 Vercel)

`webapp/` 是纯静态文件,无需构建:

1. 把项目推到 GitHub 仓库
2. 在 [Cloudflare Pages](https://pages.cloudflare.com) 或 [Vercel](https://vercel.com) 导入仓库,**根目录设置为 `webapp`**,构建命令留空
3. 部署完成后得到一个 HTTPS 链接,发给家人即可共用

## 安装到手机主屏幕

- **iPhone(Safari)**:打开链接 → 分享按钮 → "添加到主屏幕"。添加后全屏运行,且 iOS 16.4 起支持通知
- **安卓(Chrome/Edge)**:打开链接 → 菜单 → "安装应用"或"添加到主屏幕"

## 目录结构

```
菜品app/
├── webapp/                     网页版 PWA(主力版本)
│   ├── index.html              页面结构(库存/菜谱双视图 + 录入面板)
│   ├── styles.css              样式
│   ├── js/
│   │   ├── shelfLife.js        保质期知识库(食材 → 保存方式/天数/建议)
│   │   ├── store.js            库存、历史、购物清单存储层(localStorage)
│   │   ├── recipes.js          内置菜谱库 + 按库存匹配推荐
│   │   ├── ai.js               通义千问对话与视觉识别调用层
│   │   └── app.js              界面渲染与交互逻辑
│   ├── manifest.webmanifest    PWA 配置(名称/图标/独立窗口)
│   ├── sw.js                   Service Worker(离线缓存)
│   └── icons/                  应用图标
├── pages/ · utils/ · app.*     微信小程序版本(保留)
└── project.config.json         小程序开发者工具配置
```

## 后续扩展

| 功能 | 接入方式 |
| --- | --- |
| 离线推送提醒 | 需要一个小后端 + Web Push(VAPID);当前版本为"打开应用时通知",无需服务器 |
| 多设备同步 | 存储层收敛在 `store.js`,换成 Supabase 等云端只改这一个文件 |

## 注意

- 知识库天数为常见家庭保存参考值,实际以食材状态为准
- 数据存在浏览器 localStorage,清除浏览器数据会丢失;正式长期使用建议接入云端同步
