# 冰箱门墨水屏看板(ESP32)

贴在冰箱门上的常驻库存看板:每小时自动刷新一次云端家庭库存,开冰箱门也会触发刷新;
临期菜品反色高亮,路过一眼就能看到"还剩什么、什么快过期"。深度睡眠 + 墨水屏静态零功耗,电池续航以月计。

固件是**纯只读客户端**,直接复用网页版"家庭共享"的云端接口,不需要改任何服务端代码。

## 接线

| 墨水屏驱动板 | ESP32-S3 引脚 |
| --- | --- |
| VCC | 3.3V |
| GND | GND |
| DIN(MOSI) | GPIO11 |
| CLK(SCK) | GPIO12 |
| CS | GPIO10 |
| DC | GPIO9 |
| RST | GPIO8 |
| BUSY | GPIO7 |

门磁(可选,不接就把固件里 `USE_DOOR_SENSOR` 改成 0):

| 门磁引线 | 接到 |
| --- | --- |
| 一端 | GPIO4 |
| 另一端 | GND |

门磁主体贴冰箱门框,磁铁贴门,关门时两者贴近。

## 烧录步骤

1. 安装 [Arduino IDE](https://www.arduino.cc/en/software),在"开发板管理器"里搜索安装 **esp32 by Espressif**
2. "库管理器"里安装三个库:**GxEPD2**、**U8g2_for_Adafruit_GFX**、**ArduinoJson**
3. 打开 `fridge_display/fridge_display.ino`,修改顶部配置区:WiFi 名称密码、你的部署地址、家庭共享码
4. 开发板选择 **ESP32S3 Dev Module**,USB 线连接电脑,点上传
5. 上传完成后屏幕应在 30 秒内刷出库存;之后拔掉 USB 接电池即可

## 工作逻辑

上电 / 定时唤醒 / 开门唤醒 → 连 WiFi → 拉取 `GET /api/sync?code=家庭共享码` →
按剩余天数排序渲染(临期反色) → 深度睡眠一小时。
开门唤醒时会等门关上再多等 8 秒,让你用手机或语音记完账、云端同步后再刷新。

## 常见问题

- **屏幕不刷新 / 花屏**:多半是驱动型号不对,把固件里两行 `GxEPD2_BW<...>` 换另一行
- **显示"WiFi 连接失败"**:ESP32 只支持 2.4GHz WiFi,确认路由器开了 2.4G 频段
- **显示"数据拉取失败"**:检查部署地址(要带 https:// 不带末尾斜杠)和家庭共享码是否与手机上一致
- **想省电**:把 `SLEEP_SECONDS` 改大,如 4 小时 = 14400;开门唤醒不受影响

## 后续升级:语音盒子(方案 B 完整体)

在此基础上加一个 I2S 麦克风(INMP441,约 ¥10),开门时自动开始录音,
说一句"放入西红柿"松口即记账——录音上传走的也是现成的 `/api/chat` 语音识别链路。
等网页版语音用顺、提示词打磨好之后,固件加录音上传逻辑即可,硬件先按本清单买就行。
